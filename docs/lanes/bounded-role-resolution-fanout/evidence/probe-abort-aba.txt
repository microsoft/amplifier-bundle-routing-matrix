# In-product abort probe -- A-B-A', one disposable container

Probe: the bug report's own `probe-min.yaml` (one agent step, one token), run
via `amplifier tool invoke recipes operation=execute ... -b recipes -o json`
with `PYTHONFAULTHANDLER=1`. Aborts counted by exit code 134 / 139.

Only ONE thing changed between arms: the three `hooks-routing` module files in
the CLI's bundle cache. truststore was never touched.

| arm | hooks-routing | attempts | aborts |
|---|---|---|---|
| A  | stock (`main`)              | 10 concurrent + 6 sequential = 16 | **4** |
| B  | this branch                 | 20 concurrent + 6 sequential = 26 | **0** |
| A' | reverted to stock           | 10 concurrent + 6 sequential = 16 | **7** |

Stock combined: 11 aborts in 32. Patched: 0 in 26. The failure returns
immediately on revert.

Proof the patched code was the code that RAN (not just the code on disk):
`__pycache__` was deleted before arm B and regenerated during it, and the
resulting `.pyc` files contain the new `max_concurrent_role_resolutions` and
`inflight_model_lists` symbols.
